## 🚀 Ключевые особенности

- **Современная база (Minecraft 1.21.8 / Fabric):** Полная поддержка последних версий игры, компонентов оружия (Mace, Wind Charge) и обновленного сетевого протокола.
- **Интеллектуальная боевая система:**
  - `CrystalPlanner` — просчет взрывов, геометрии и траекторий кристаллов без фантомов.
  - `CombatInteractionGuard` — синхронизация клиентских пакетов и подтверждение блоков сервера (защита от ghost-блоков на Grim/Matrix).
- **Биомеханические ротации (Anticheat Bypass Framework):**
  - Поддержка алгоритмов под **GrimAC, Matrix, Matrix Advanced, ShardAC, Legit, Smooth**.
  - Настоящее квантование под аппаратный **Mouse GCD** чувствительности мыши.
  - 3D-блуждающие органические мультипоинты (Organic Volume Roaming).
  - Кривые нелинейного сглаживания Роберта Пеннера (**Easing Functions**: Cubic, Quad, Back для овершутов).
  - Многослойный гармонический тремор вместо палящегося белого шума.
- **Кастомный графический движок:**
  - Анимированный **ClickGUI** и кастомизируемый **HUD**.
  - Шейдеры неба (`SkyShader`), визуализация траекторий (`Predictions`, `Tracers`), кастомный рендеринг рук и предметов.
- **Инструменты тестирования:** Встроенный модуль `FakePlayer` (с клонированием инвентаря и хитбоксов) для локальной отладки прямо в одиночной игре.

## 🛠️ Архитектура и обходы

Клиент использует модульную архитектуру на Fabric API и Mixin-трансформерах:

```text
tech.javelin/
├── base/
│   ├── events/       # Легковесный реактивный Event-Bus (IEvent, EventManager)
│   ├── managers/     # Менеджеры модулей, тем, друзей и команд
│   └── util/         # Математика, Easing-анимации, Raycast, MouseGCD
└── features/
    ├── display/      # ClickGUI экраны и HUD компоненты
    └── module/       # Реализация модулей по категориям (Combat, Visual, Movement, etc.)
```

### Принципы античит-инженерии клиента:
1. **Никаких синтетических шагов угла:** Каждое изменение взгляда выравнивается по формуле:
   ```text
   DeltaTheta = round(DeltaTheta / GCD) * GCD, где GCD = (sensitivity * 0.6 + 0.2)^3 * 1.2
   ```
2. **Асимметрия осей (Pitch / Yaw):** Учет анатомического сопротивления кисти и разницы в скорости горизонтального и вертикального довода.
3. **Безопасная пакетная гигиена:** Отказ от десинхронизирующих тихих пакетных свапов в пользу ванильных очередей событий `EventPreMotion` / `EventPostMotion`.

## 💻 Сборка из исходников

### Требования
- **JDK 21** (рекомендуется [Eclipse Temurin](https://adoptium.net/) или BellSoft Liberica)
- **Git**

### Инструкция по сборке

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/javelin-client.git
   cd javelin-client
   ```

2. Скомпилируйте мод с помощью Gradle Wrapper:
   * **Windows (PowerShell / CMD):**
     ```powershell
     .\gradlew build
     ```
   * **Linux / macOS:**
     ```bash
     chmod +x gradlew
     ./gradlew build
     ```

3. Готовый `.jar` файл появится в папке:
   ```text
   build/libs/javelin-1.0.0.jar
   ```

4. Поместите скомпилированный `.jar` в папку `.minecraft/mods` (требуется установленный **Fabric Loader 1.21.8** и **Fabric API**).
